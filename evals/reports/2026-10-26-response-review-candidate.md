# 응답 검토 후보 평가 — 출시 보류 (2026-10-26)

**출시·병합·전역 설치를 보류한다.** 후보 2는 전체 평가에서 통과가 늘었지만, 독립 검토를 사용할 수 없을 때 기존 동작 설명을 요청하지 않은 정책 결정으로 바꾸는 실패가 남았다. 패키지와 기본 설치 버전은 **2.1.2**이며 새 버전 태그를 만들지 않았다. 현재 브랜치는 출시되지 않은 후보 2 소스를 보존한다.

아래 수치는 최종 익명 평가 260건과 두 건의 등급 조정 결과다. 원판정과 조정 근거는 [최종 JSON](2026-10-26-response-review-candidate.json)에 함께 보존했다.

| --- | --- | --- |
| 전체 번들, 각 72건 | 61 / 11 / 0 | 후보 2: **66 / 5 / 1** |
| 실제 파일 로딩, 각 36건 | 28 / 8 / 0 | 후보 1: 32 / 4 / 0 |
| 후보 2 실제 파일 로딩, 12건 부분집합 | 별도 대응 수치 없음 | 11 / 1 / 0 |
| 확장 사례, 각 16건 | 13 / 3 / 0 | 후보 2: 15 / 1 / 0 |

출시를 막는 **F208**은 Haiku 5.5 low의 기존 코드 설명이다. 두 번째 외부 청구의 성공을 단정하고, 끝에서 다음과 같이 정책의 수용 여부를 묻는다.

> Does the charge service reject or deduplicate a repeated `id` (for example, through an idempotency key)? That determines whether the current order is acceptable.

사용자는 변경된 코드가 뜻하는 바를 설명해 달라고 했으며 정책 결정을 요청하지 않았다. 평균 통과 수가 늘어도 이 범위 이탈 실패는 해소되지 않았다. F128·F228은 독립 검토자 `v220_release_code_review`가 원등급을 보지 않고 재검토했다. 둘 다 핵심 제어 흐름은 맞고 이미 푼 사례를 다시 묻는 결함이므로, 고정된 기준에 따라 실패에서 경고로 조정했다. F128의 반환값은 두 번째 호출의 결과라는 기호적 표현으로 결정할 수 있다. 전체 번들의 원판정은 기준본 61/10/1, 후보 2 66/4/2였으며 F208은 그대로 실패다.

후보 1의 준비된 응답 검토에 이어 후보 2는 독립 검토가 없을 때의 로컬 수정 절차를 명시했다. 이후 후보 3의 라우팅 수정은 22개 탐색 실행 중 해당 오류를 세 번 반복한 시험의 세 번째에서 정책 결정으로 넘어갔다. 후보 4의 추가 범위 제한도 11개 탐색 실행 중 같은 세 번 모두에서 정책 결정을 요구했다. 두 가설을 채택하지 않고 후보 2 소스를 복원했다. 이 탐색 실행의 나머지 응답에는 의미 평가 점수를 만들지 않았다. 선택한 응답, 원문 인용, 소스 해시는 최종 JSON에 남겼다.

전체 번들은 GPT-6 Luna/Sol/Astra와 Claude Haiku/Sonnet/Opus 5.5의 low/high 조합마다 여섯 사례를 사용했다. Claude는 CLI, GPT는 데스크톱 에이전트에서 실행했으므로 호스트가 다르다. 최종 의미 검토자는 Opus 5.5 high이며 모델·버전 표시를 가렸다. 네이티브 실행 안의 독립 검토자는 Opus 5.5지만 **검토자 effort는 확인되지 않았다**. 후보 2의 네이티브 부분집합은 Haiku low와 Sonnet high이며 36건 전체 행렬을 다시 수집한 결과가 아니다.

후보 1의 GPT JSON 네 건에는 형식 오류가 있었다. 원본을 보존하고 줄바꿈·따옴표 문법만 정규화한 뒤 평가했다. 후보 2 비교에서는 GPT 기준본도 같은 영어 응답·유효한 JSON 지시로 새로 수집했다. 원본 여섯 사례와 평가 기준은 바꾸지 않았다. 검토 누락은 프로토콜 미준수이며 자동으로 의미 평가 실패가 되지 않는다. 실제 도구 실패가 있었던 응답도 의미 평가는 가능하지만 실행 성공으로 바꾸지 않는다. 작은 확률적 표본과 판정 변동이 있으므로 성공률 보장, 모델 순위, 스킬의 인과적 효과를 주장하지 않는다.

후보 1의 쓰기 허용 워크플로 검증은 5건 통과·1건 경고였다. 승인 전 세 턴은 수정하지 않았고 승인 후 독립 수용 검사를 통과했다. 경고는 캐시 갱신을 삭제와 함께 빈 상태로 그린 도식이다. 이를 후보 2의 신규 실행으로 재분류하지 않았다.

저장소 테스트 83개, 정적 검사 45개, 최종 집중 검사 24개가 통과했다. 후보 2 복원 후 격리 설치의 13개 파일 일치와 양쪽 스킬 검증도 통과했다. 기존 전역 설치는 변경하지 않았으며, 두 매니페스트의 버전이 2.1.2이고 11개 파일이 v2.1.2 태그와 바이트 단위로 일치하는지 읽기 전용으로 확인했다. 이러한 검사는 남은 의미적 실패를 해소하지 않는다.

[후보 1 단계별 증거](2026-10-26-response-review-candidate-stage1.json)에는 앞선 원평가·재심·실행 실패를 별도로 보존했다. [최종 증거](2026-10-26-response-review-candidate.json)는 원문 인용 검증, 최종 판정, 실행과 검토 수행 여부, 소스 해시, 탐색 가설의 실패를 담는다. 원시 실행 로그·세션 ID·개인 경로·인증 정보는 공개하지 않는다.

PR #6 생성 직후 커밋 `826eedc`에서 Haiku 5.5 low로 실제 스킬 로딩 스모크 두 건을 실행했다. 실행은 2/2 통과했고, 변경된 코드 설명은 완료된 Opus 5.5 검토를 거쳐 요청하지 않은 정책 결정을 묻지 않았다. 질문 생략 사례도 질문 없이 끝났지만 독립 검토는 생략했다. 이 스모크를 익명 평가 점수에 합치지 않았으며 기존 정책이 보장됐다는 표현까지 입증한 것은 아니다. Node 22·24의 push/PR CI도 통과했다. 출시 보류 결정은 바뀌지 않는다.
